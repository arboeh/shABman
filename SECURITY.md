# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.5.x-beta | ✅ |
| < 0.5.0 | ❌ |

## Reporting a Vulnerability

Please use **GitHub Private Vulnerability Reporting**:
Settings → Security → Report a vulnerability

Do NOT open a public issue for security vulnerabilities.
Response within 48 hours.
